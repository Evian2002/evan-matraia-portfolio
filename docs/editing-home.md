# Editing the Home Page

This app is React, so the "HTML" you edit is JSX inside `.tsx` components.

## Where to edit

- Top navigation: `src/features/home/components/HomeNav.tsx`
- Hero section (headline, intro text, portrait image): `src/features/home/sections/HeroSection.tsx`
- Software + skills chips: `src/features/home/sections/SkillsSection.tsx`
- Portfolio cards: `src/features/home/sections/PortfolioSection.tsx`
- Contact form + contact text: `src/features/home/sections/ContactSection.tsx`
- Footer: `src/features/home/sections/FooterSection.tsx`

## Content lists (easy to tweak)

- Meta title/description + arrays (tools, skills, projects): `src/features/home/content.ts`
